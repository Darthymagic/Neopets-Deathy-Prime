Neopets Darthy Prime — Windows 10 install
========================================

1. Right-click DarthyPrime-Windows10.zip → Extract All…
2. Extract to a simple folder such as:
     C:\Users\YOURNAME\Documents\DarthyPrime
3. Open Chrome (or Edge / Brave) and go to:
     chrome://extensions
   Edge uses edge://extensions
4. Turn on Developer mode (top right).
5. Click Load unpacked.
6. Select the folder named neopets-darthy-prime
   that DIRECTLY contains manifest.json
   (not the parent folder, not the zip).

If Chrome says it cannot load the manifest or a CSS file:
- You selected the wrong folder. Go one level in or out until you see manifest.json in that folder.
- Do not load the zip itself.
- Do not load a folder that only contains another neopets-darthy-prime folder.

After updating, click Remove on the old extension, then Load unpacked again.
Pin the extension if you like.

Works on https://www.neopets.com/*
